# UML 图渲染说明

六张图均由本目录中的 `.puml` 文件绘制，PNG 是对应的高清导出结果。源码指定了中文字体、220 dpi 和 Smetana 布局。安装 Java 和 PlantUML 后，可在此目录执行：

```bash
java -Djava.awt.headless=true -jar plantuml.jar -checkonly *.puml
java -Djava.awt.headless=true -jar plantuml.jar -tpng *.puml
```

设计图按用途分为：类图、组件图（结构性图）；用例图、商品状态图、预约状态图（行为性图）；预约时序图（交互性图）。
